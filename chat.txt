# Complete Summary — Voice Authenticity OpenEnv Competition Journey

---

## The Beginning — Idea Selection

You came with an original idea for a **Voice Authenticity Scoring Environment** for the Meta x HuggingFace OpenEnv competition. The competition required building a real-world RL environment where an AI agent learns through `step()`, `reset()`, `state()` API.

After evaluating multiple approaches, the final decision was:
- **Domain:** Synthetic/AI-generated voice detection
- **Why:** Voice fraud is a documented real problem, novel domain, no other submission would do this
- **Architecture:** Pre-extracted audio features served as observations, LLM agent classifies real vs synthetic

---

## Technical Architecture Built

### The Core Idea
```
Real audio (LJSpeech) + Fake audio (ElevenLabs/Coqui)
            ↓
    Feature extraction (offline, once)
            ↓
    48-dimensional feature vector per clip
            ↓
    Environment serves vectors to LLM agent
            ↓
    Agent classifies: real(0) or synthetic(1) + confidence
            ↓
    Grader scores with partial reward signal
```

### The 48-Dimensional Feature Vector
| Index | Feature | Why It Matters |
|-------|---------|---------------|
| 0-19 | MFCC means | Timbre/spectral shape |
| 20-39 | MFCC std devs | Variation — fakes are too stable |
| 40 | Zero crossing rate | Signal changes |
| 41 | Spectral centroid | Brightness |
| 42 | Jitter | Frequency instability — KEY discriminator |
| 43 | Shimmer | Amplitude instability — KEY discriminator |
| 44 | HNR | Harmonics-to-noise — fakes too clean |
| 45-47 | Compression artifacts | For Task 2 |

## The 3 Tasks

### Task 1 — Clean Detection (Easy)
- Clean, unmodified audio features
- Binary reward: correct=0.95, wrong=0.05
- Expected agent score: 0.7–1.0

### Task 2 — Compressed Detection (Medium)
- Same audio after codec compression simulation
- Jitter/shimmer degraded, artifacts added
- Partial reward based on confidence calibration
- Expected agent score: 0.4–0.7

### Task 3 — Adversarial Detection (Hard)
- Synthetic audio engineered to mimic real speech
- Fake samples have jitter/shimmer pushed into real range
- Real samples pushed toward synthetic range
- 8% label noise added for ambiguity
- No clean threshold separates classes
- Expected agent score: 0.3–0.6

## The Reward Function (Your Biggest Differentiator)

```python
def grade(true_label, action, difficulty):
    correct = (label == true_label)
    confidence = action["confidence"]

    if difficulty == "easy":
        return 0.95 if correct else 0.05

    elif difficulty == "medium":
        if correct:
            return 0.6 + 0.35 * confidence   # max 0.95
        else:
            return max(0.05, 0.2 - 0.3 * confidence)

    elif difficulty == "hard":
        if correct:
            base = 0.5
            calibration_bonus = 0.45 * (1 - abs(confidence - 0.7))
            return base + calibration_bonus
        else:
            return 0.15 if confidence < 0.4 else 0.05
```

**Why this is superior:** Confidence calibration. Wrong + uncertain = small penalty. Wrong + overconfident = heavy penalty. This teaches agents to express appropriate uncertainty — research-grade design.

## The 2-Step Interaction Loop (Major Enhancement)

Added after feedback that single-step classification looks too simple:

**Step 1 — Analyze phase:**
```json
{"focus": ["jitter", "shimmer", "hnr"], "label": 0, "confidence": 0.5, "reasoning": "Requesting focused analysis"}
```
Returns reward=0.0, done=false

**Step 2 — Decide phase:**
```json
{"label": 1, "confidence": 0.75, "reasoning": "Low jitter indicates synthetic"}
```
Returns actual reward, done=true

This transforms the environment from static classification into a genuine agentic system with partial observability and action-dependent state transitions.
